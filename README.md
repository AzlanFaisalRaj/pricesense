# PriceSense - Used Car Price Predictor

Predicts the fair market price of a used car from make, model, year, mileage, engine and city.

## Problem
Buyers and sellers on car marketplaces rarely know what a used car is actually worth. This project builds a regression model that estimates a fair price, and serves it through a Streamlit web app.

## Dataset
PakWheels used cars dataset (Kaggle).

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn, Streamlit

## Status
Work in progress. Currently: project setup and data exploration.

## Planned

- Feature engineering (car age, mileage per year, brand tier)

- Streamlit app with price range and feature importance
